# 🚀 HireHubJA

> A modern and scalable job hiring platform that connects job seekers with employers and companies.

HireHubJA is a full-stack recruitment platform designed to simplify the hiring process. It provides a complete ecosystem for **Job Seekers, Employers, Companies, and Administrators** to manage jobs, applications, profiles, and recruitment activities from a single platform.

---

## ✨ Features

### 👨‍💻 Job Seeker

- Create and manage professional profiles
- Search and browse available jobs
- Apply for jobs
- Track job applications
- Manage resumes and personal information
- Update profile information
- View job details and requirements

### 🏢 Employer

- Create and manage company profiles
- Post new job vacancies
- Update and manage job postings
- View received applications
- Review candidate profiles
- Manage recruitment activities

### 🏛️ Company

- Company profile management
- Publish job opportunities
- Manage posted jobs
- Review applicants
- Manage hiring-related information

### 🛡️ Admin Dashboard

- Manage users
- Verify and manage companies
- Manage employers and job seekers
- Review job postings
- Manage applications
- Monitor platform activities
- User status management
- Administrative controls and verification
